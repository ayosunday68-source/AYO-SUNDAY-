NaijaBite Food Ordering App
===========================

Files included:
- index.html — page structure
- style.css — yellow theme, layout, buttons and food cards
- script.js — food list, prices, search, category filters, cart and demo checkout

Run on your computer:
1. Keep all three files in the same folder.
2. Open index.html in a browser.

Use in CodePen:
1. Create a new Pen.
2. Paste the body content/markup from index.html into the HTML panel.
3. Paste style.css into the CSS panel.
4. Paste script.js into the JS panel.

Note: This is a front-end demo. Checkout does not send real orders or process payments.
